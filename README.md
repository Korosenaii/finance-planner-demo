# Finance Planner — démo web (MVP)

Démo publique compilée du MVP **Finance Planner** — une application de
planification financière personnelle (budgets, objectifs, achat de propriété,
projection de retraite transparente).

- **Toutes les données affichées sont fictives** (jeu de données démo).
- Ce dépôt ne contient que les artefacts compilés; le code source vit dans un
  dépôt privé.
- Outil éducatif : les résultats sont des projections, pas des garanties.

Créé par **Ismaël Guindo & Boubacar Kane**.
